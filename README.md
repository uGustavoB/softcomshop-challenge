## 📚 Sobre este repositório

Este repositório reúne todos os projetos desenvolvidos ao longo da formação, servindo como um registro da evolução técnica e da aplicação prática dos conhecimentos adquiridos durante o curso.

Ao longo da formação, os projetos foram construídos com foco em aprendizado progressivo, começando por fundamentos e avançando para soluções mais completas e próximas de cenários reais do mercado. Cada projeto explora diferentes conceitos, tecnologias e desafios, permitindo consolidar habilidades como:

-   Desenvolvimento de aplicações back-end e front-end
-   Criação e consumo de APIs REST
-   Modelagem e integração com banco de dados
-   Boas práticas de organização de código e arquitetura
-   Uso de ferramentas modernas como Docker, Git e frameworks atuais
-   Resolução de problemas e adaptação a novas tecnologias

O repositório está organizado de forma que cada pasta represente um projeto independente, com seu próprio contexto, objetivos e nível de complexidade. Dessa forma, é possível acompanhar claramente a progressão do aprendizado, desde projetos guiados durante as aulas até um projeto final mais robusto e autoral.

## 🖊️ Projetos desenvolvidos

- [RestauraSoft](https://github.com/uGustavoB/softcomshop-challenge/tree/main/restauraSoft/) - Projeto final da formação, desenvolvido com o objetivo de consolidar e demonstrar os conhecimentos adquiridos ao longo do curso. O projeto simula um sistema completo para gestão de restaurante, abordando desde a modelagem de dados e construção de APIs até a integração com o front-end, além de lidar com desafios reais como resolução de impedimentos, tomada de decisões técnicas e conceitos do princípios SOLID.
- [SoftcomPDV](https://github.com/uGustavoB/softcomshop-challenge/tree/main/softcompdv) - Projeto prático desenvolvido progressivamente durante as aulas da formação. Teve como foco aplicar, semana a semana, os conceitos estudados em sala, permitindo acompanhar a evolução técnica individual, reforçar boas práticas de desenvolvimento e compreender o fluxo completo de construção de um sistema, desde a base até funcionalidades mais avançadas.

## 🚀 Projetos desenvolvidos anteriormente

- [FinSupp-API](https://github.com/uGustavoB/FinSupp-API) - Aplicação REST desenvolvida com Spring Boot que oferece uma solução completa para controle financeiro pessoal. Ela permite o gerenciamento de contas bancárias, cartões, categorias, transações, assinaturas e faturas, juntamente com autenticação JWT para segurança robusta.
- [Finsupp-Angular](https://github.com/uGustavoB/FinSupp-Angular) - Aplicação frontend para consumo da FinSupp-API, trazendo uma interface intuitiva, responsiva e alinhada com padrões modernos de UX/UI. Utilizei o Angular para garantir modularidade, reutilização de componentes e integração eficiente com o backend.
- [LexoBank](https://github.com/uGustavoB/LexoBank) - O LexoBank é um sistema bancário em arquitetura cliente-servidor desenvolvido em Python, que permite criação de contas, depósitos, saques, transferências e consulta de histórico. Utiliza sockets para comunicação em rede, threading para múltiplas conexões e estruturas de dados como árvore AVL e pilha para gerenciar contas e transações de forma eficiente.
- [Weather Infos](https://github.com/uGustavoB/Projeto-Weather-Infos) - O Weather Infos é uma aplicação desenvolvida em ReactJS que consome a API do OpenWeather para exibir informações climáticas em tempo real. O usuário pode favoritar cidades, que são salvas no localStorage, permitindo acesso rápido posterior.
